# MelaCMS

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**MelaCMS** born with a real necessity and paradigm shift in devloping small and simple to complex websites where CMS it's need it to give the client controls.
MelaCMS wants to be the Wordpress alternative for those freelances or studios that need a modern agentic coding solutions for all they're clients. Wordpress it's no more an option, it "rejects" the agentic coding and needs payd plugins at least for translations like WPML and it's a well architected nightmare.
This repo should be like the wordpress basic, with "super-admin", "admin", "editors" etc... to manage the websites and it's content.
The freelance should clone the repo and start to build the specific website already with CI and Deployment if need it  through.

**CMS built in Laravel with Filament, Blade, Alpine and components island Vue for widget, all multilanguage with i18n**
